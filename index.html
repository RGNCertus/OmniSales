04 · EVENTOS STREAMING

Topic: omnisales-events

El productor Kafka emite 6 tipos de evento en tiempo real. El consumidor Spark Structured Streaming los procesa en micro-batches de 10 segundos.

venta_iniciada 25%
venta_completada 30%
venta_devuelta 10%
stock_bajo 12%
feedback_recibido 10%
descuento_aplicado 13%
omnisales-broker · topic: omnisales-events
# Ejecutar productor de eventos
$ docker compose exec spark python src/02_generate_streaming_events.py --events 1500 --delay 0.05

06 · EJECUCIÓN

Comandos del proyecto

Paso 1 — Levantar Docker
docker compose up -d
Paso 2 — Generar datos históricos
docker compose exec spark python src/01_generate_batch_data.py
Paso 3 — ETL Batch + KPIs
docker compose exec spark python src/03_batch_etl_spark.py
Paso 4 — Generar gráficos
docker compose exec spark python src/05_visualizations.py
Paso 5a — Consumidor streaming
docker compose exec spark python src/04_streaming_spark_kafka.py --duration 120
Paso 5b — Productor de eventos
docker compose exec spark python src/02_generate_streaming_events.py --events 1500 --delay 0.05
